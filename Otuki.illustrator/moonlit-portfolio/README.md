# MOONLIT STUDIO — イラストレーター・ポートフォリオ

月と星をモチーフにした、HTML / CSS / JavaScript のポートフォリオテンプレートです。

## ファイル
- `index.html` — ページ構造と文章
- `style.css` — デザイン、レスポンシブ対応、アニメーション
- `script.js` — 星の生成、スクロール表示、作品フィルター、詳細モーダル、スマホメニュー
- `img/` — ご自身の作品画像を置くフォルダ

## GitHub Pagesへの反映
1. 既存リポジトリのファイルを念のためバックアップする。
2. このZIPを解凍する。
3. `index.html`、`style.css`、`script.js`を、GitHubリポジトリのトップ階層（index.htmlがある場所）にアップロードする。
4. `img`フォルダの中身も同じ名前・階層でアップロードする。
5. GitHubで `Commit changes` を実行する。GitHub Pagesが自動で更新される。

## 公開前に必ず変更すること
- `index.html` の `YOUR-EMAIL@example.com` を実際に使うメールアドレスに変更。
- `href="#"` になっているSNSリンクを実際のプロフィールURLに変更（使わないSNSは削除してOK）。
- サンプルの作品名・説明文・制作年を自分の内容に合わせる。
- 作品画像を用意し、HTML内の `data-image="img/work-01.jpg"` などの名前と一致させる。
- 仮の作品カードはCSSで作ったプレースホルダーです。実際の作品を公開する前に差し替えてください。

## 作品画像を表示する方法
例として `img/work-01.jpg` を用意したら、対応する作品カード内に次のような画像要素を入れ、背景用の装飾要素は不要なら削除できます。
`<img class="real-art-image" src="img/work-01.jpg" alt="作品タイトル">`
簡単に差し替えられるよう、まずは画像ファイルを `img` に入れ、HTMLのファイル名を合わせるところから進めてください。

このテンプレートには実際の送信先を持つ問い合わせフォームは含まれず、問い合わせボタンはメールアプリを開く方式です。
